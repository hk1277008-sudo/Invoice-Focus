PHASE 3 — HANDLE 404 URLS CORRECTLY
==================================================

Investigate every public URL currently reported as 404/not found.

For each URL determine:

- Does the page still exist?
- Was it intentionally removed?
- Is there a replacement page?
- Is the URL supposed to be public?
- Is the URL supposed to be private?
- Is there an equivalent current URL?

Use this decision logic:

CASE 1:
If the URL SHOULD exist as a public SEO page:
→ restore/fix the route
→ ensure HTTP 200
→ add proper SEO metadata
→ add canonical URL
→ include in sitemap if appropriate

CASE 2:
If the URL was permanently removed and there is a highly relevant replacement:
→ implement a permanent 301 redirect to the most relevant replacement

Do NOT redirect unrelated URLs just to avoid 404s.

CASE 3:
If the URL was permanently removed and has no meaningful replacement:
→ leave it as a proper 404 or use 410 where technically appropriate
→ remove it from the sitemap
→ remove internal links pointing to it

CASE 4:
If the URL is a private/application route:
→ it should NOT be in the public SEO sitemap
→ do not attempt to make it indexable

Do not create fake pages just to eliminate Search Console errors.
